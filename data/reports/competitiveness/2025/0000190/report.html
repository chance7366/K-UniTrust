1.1 대학 기본정보 및 진단 개요

초당대학교는 전남 서남권에 위치한 사립 소규모 대학교(재학생 2,375명)로, 2025년 K-UniTrust 대학경쟁력 분석 결과 종합지수 28.0점을 기록하여 동종 151개 대학 중 133위로 E등급(복합 구조위기형)으로 진단되었습니다. 본 진단은 동종 4년제 대학교 집단을 기준으로 절대평가형 선형 보간법을 적용하여 산출되었으며, 8대 핵심지표 중 신입생충원율(0.0점), 중도탈락율(0.0점), 재학생충원율(16.0점) 등 학생충원 부문의 전반적인 지표가 동종 집단 하위권에 머무르고 있어 비상 관리 조치가 시급한 상황입니다.

3. 세부 산출 공식 (절대평가형 선형 보간법)

원천 수치 X, 집단 내 하위 10% 백분위수 P₁₀, 상위 10% 백분위수 P₉₀, 지표 배점 M 설정 시 점수 S 산출식은 다음과 같습니다.

3.1 정방향 지표: X ≥ P₉₀ 이면 S = M, P₁₀ < X < P₉₀ 이면 S = M × (X − P₁₀) / (P₉₀ − P₁₀), X ≤ P₁₀ 이면 S = 0

3.2 역방향 지표: X ≤ P₁₀ 이면 S = M, P₁₀ < X < P₉₀ 이면 S = M × (P₉₀ − X) / (P₉₀ − P₁₀), X ≥ P₉₀ 이면 S = 0

※ 세부지표의 100점 만점 환산지수 = (S / M) × 100
