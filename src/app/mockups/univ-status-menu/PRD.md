# 대학현황 메뉴 재구성 PRD v0.1

> 상태: **목업 단계** · 프로덕션 사이드바 미적용  
> 목업 URL: `/mockups/univ-status-menu`

## 1. 변경 배경

| 현재 | 변경 후 |
|------|---------|
| 대학현황: 학교개황, 대학위치, **학교코드**(최상위) | 대학현황: 학교개황, 대학위치 + **대학알리미·재정알리미·지역인구·분석대상** |
| 재정분석지표 > 지역인구: 지역소멸, 학령인구, 출신지역 | **지역소멸·학령인구** → 대학현황/지역인구로 이동 |
| — | **출신학교** → 대학현황/대학알리미 (기존 출신지역 화면과 동일) |

목적: 재정분석지표·대학경쟁력분석의 **기초자료 DB**를 대학현황 아래로 통합.

## 2. 목표 메뉴 트리

```
대학현황
├── 학교개황
├── 대학위치
├── 대학알리미
│   ├── 학교코드          ← 기존 univ-map/school-code 이동
│   ├── 신입생충원        ← 기존 finance-analysis/freshman-enrollment-rate
│   ├── 재학생충원
│   ├── 중도탈락
│   ├── 재적학생          ★ 신규
│   ├── 평균등록금        ★ 신규
│   └── 출신학교          ← 기존 finance-analysis/origin-region
├── 재정알리미            ★ 신규 그룹
│   ├── 교비_자금
│   ├── 교비_대차
│   ├── 교비_운영
│   ├── 산단_자금
│   ├── 산단_대차
│   ├── 산단_운영
│   └── 수익용재산
├── 지역인구
│   ├── 지역소멸          ← 기존 finance-analysis/regional-decline
│   └── 학령인구
└── 분석대상              ★ 신규 (서브메뉴 없음)
```

## 3. 화면 패턴

- **기존 화면 이전**: 현재 프로덕션 대시보드 그대로 재사용 (데이터·업로드·필터 유지)
- **신규 화면**: 재정분석지표/신입생충원율 **대학별DB** 패턴 (에메랄드 헤더 · 대학별DB/통계분석 탭 · 필터 · 업로드)
- **분석대상**: 단일 화면, 서브메뉴 없음

## 4. Phase 로드맵

|-------|------|

| **3** | 재정분석지표에서 이동된 항목 정리, 경쟁력분석 기초자료 연동 |
