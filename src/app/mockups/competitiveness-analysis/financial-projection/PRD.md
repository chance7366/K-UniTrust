> 구 경로 `/analysis/competitiveness-analysis/trend` → 기본설정으로 리다이렉트

## 작업 흐름

1. **기본설정** (전체 대학 공통) — 대상대학(대학·전문대학), 기초자료 생성, 거시·CPI
2. **시나리오** (전체 대학 공통) — 낙관/기본/비관/한계. 학교별 CPI·시나리오 없음
3. **분석실행** — 대상대학 전체에 동일 시나리오 적용
4. **대학별추계** — 실행 후에만 개별대학 조회 (추계결과·한계진단·대응전략)

## 기본설정

- **대상대학**: 대학 / 전문대학 코호트 분리, 사립·결산 제출 교
- **기초자료 생성**
  - 대학현황(정원·충원·중탈·재적·등록금·출신) 지표 선정
  - 재정분석지표(자금확보·전입·수혜·운영계산서 보수·관리운영비·장학금) 선정
  - 공통 계정분류로 **대학별 FC/VC** 산출
  - 임금 = 해당 대학 교비 보수 5개년 CAGR
- **거시·CPI**: 학령인구 시도·시군구 연령이동, 지역소멸지수, CPI — **전체 공통**

## 시나리오

등록금·정원 what-if·FC절감·충원 가감·국고 증감. CPI는 기본설정 값 표시만.

## 확정 가정

- 정원 중장기 계획 없음 · 비전임 비중 없음
- 가용자금 초 = 교비 이월(유동자산−유동부채+단기차입) + 임의기금 + 원금보존기금. 산단 제외
- 교육부 한계대학 지정 문구 사용 안 함
